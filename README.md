# 《明星志愿 3》宽屏高分辨率优化补丁

这是一个面向 Windows 版《明星志愿 3》的非官方 Direct3D 9 兼容补丁。项目通过代理 `d3d9.dll` 调整游戏的显示设备、渲染分辨率和界面布局，使原本以 800×600 为基础设计的游戏能够在现代宽屏显示器上以更高分辨率运行。

本项目仅供个人学习、研究和非商业用途，与游戏开发商、发行商及权利人无关。游戏名称、商标、美术、音乐和其他游戏内容的权利归各自权利人所有。本项目不包含游戏本体或其资源，使用者需自行合法持有《明星志愿 3》。

## 主要功能

- 将游戏切换为稳定的窗口化输出，可选择普通窗口或无边框窗口。
- 支持 1280×720、1600×900、1920×1080、2560×1440 等常见 16:9 分辨率。
- 支持 800×600 至 7680×4320 范围内的自定义输出尺寸。
- 可使用目标分辨率创建原生 D3D9 后备缓冲，改善 3D 场景在高分辨率下的清晰度和宽屏视野。
- 对原始 800×600 UI 视口进行居中或宽屏拉伸处理。
- 自动重排主要界面、HUD、地图标记、人物状态气泡、日程界面、相册和剧情 CG 等特殊界面，尽量保持画面与点击区域一致。
- 不直接修改 `Stardom3.exe` 或游戏原始 DLL；删除补丁文件即可停用。
- 将运行信息写入 `Stardom3.Widescreen.log`，便于排查加载和兼容性问题。

## 使用方法

### 1. 准备文件

使用 Release 包中的以下两个文件：

- `d3d9.dll`
- `Stardom3.Widescreen.ini`

自行构建时，DLL 位于构建目录；默认配置文件位于本仓库的 `config` 目录。

### 2. 安装

1. 退出游戏。
2. 找到 `Stardom3.exe` 所在的游戏根目录。
3. 如果该目录已有 `d3d9.dll`，请先将其备份；其他 D3D9 注入器或补丁可能与本项目冲突。
4. 将 `d3d9.dll` 和 `Stardom3.Widescreen.ini` 复制到 `Stardom3.exe` 同一目录。
5. 根据显示器分辨率编辑 INI，然后正常启动游戏。

推荐的 1920×1080 配置：

```ini
[Widescreen]
Enabled=1
Width=1920
Height=1080
Borderless=0
NativeRender=1
UIScaleMode=2
UnifiedUILayout=1
```

2K 显示器只需改为：

```ini
Width=2560
Height=1440
```

第一次运行后，可查看游戏目录中的 `Stardom3.Widescreen.log`，确认代理 DLL 已成功加载及实际使用的后备缓冲尺寸。

## 配置说明

所有选项均位于 INI 的 `[Widescreen]` 节中：

| 选项 | 取值 | 说明 |
| --- | --- | --- |
| `Enabled` | `0` / `1` | 是否启用补丁。设为 `0` 时原样转发游戏的设备创建请求。 |
| `Width` | `800`–`7680` | 游戏窗口客户区及原生渲染的目标宽度。默认 `1920`。 |
| `Height` | `600`–`4320` | 游戏窗口客户区及原生渲染的目标高度。默认 `1080`。 |
| `Borderless` | `0` / `1` | `0` 为普通窗口，`1` 为无边框窗口。 |
| `NativeRender` | `0` / `1` | `1` 使用目标分辨率原生渲染；`0` 保留 800×600 逻辑后备缓冲作为兼容模式。推荐设为 `1`。 |
| `UIScaleMode` | `0` / `1` / `2` | `0` 保留原始左上角 UI；`1` 居中并保持 4:3 比例；`2` 将 UI 视口扩展到整个宽屏。随附配置使用 `2`。 |
| `UnifiedUILayout` | `0` / `1` | 启用游戏 UI 控件的统一宽屏重排和相关特殊界面修正。推荐设为 `1`。 |
| `TitleScreenMode` | `0` / `1` | 标题画面显示方式。`0` 保留原始 800×600 居中页面；`1` 等比放大到屏幕高度并保留左右侧翼。推荐设为 `1`。 |

以下选项主要用于开发和故障诊断，普通玩家建议保持 `0`：

- `UIDrawDiagnostics`
- `SuppressTransparentUI`
- `UIContainerProbe`
- `SuppressProxyContainers`
- `GUIRuntimeProbe`

如果出现界面错位，可先尝试 `UIScaleMode=1`；如果原生渲染在特定显卡或兼容层下异常，可尝试 `NativeRender=0`。

## 卸载与恢复

退出游戏后，从 `Stardom3.exe` 所在目录删除：

- `d3d9.dll`
- `Stardom3.Widescreen.ini`
- `Stardom3.Widescreen.log`（如果存在）

如果安装前备份过其他同名 `d3d9.dll`，再将备份恢复原名。补丁本身不会修改游戏原始 EXE 或 DLL。

## 从源码构建

游戏是 32 位程序，因此必须生成 Win32/x86 版本。需要 Visual Studio C++ 工具链、Windows SDK 和 CMake 3.20 或更高版本。

```powershell
cmake -S . -B build -A Win32
cmake --build build --config Release
```

构建完成后，将生成的 `d3d9.dll` 与 `config/Stardom3.Widescreen.ini` 一起放入游戏目录。
