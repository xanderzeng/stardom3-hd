# 大型活动页面适配

`Office/BigActive.txt` 是直属主 GUI 根的 800×600 页面，包含 (150,96)、459×413 的活动列表卡片。页面及全部活动行、进度、滚动和关闭控件通过 `ScaleAspectFitSubtree` 放大到居中的 4:3 视口。后续列表移动使用控制器提交的原始坐标，避免选中行或滚动状态被模板位置覆盖。

`Office/ActiveOption.txt` 的外层是输出尺寸透明根，360×370 的 `PlaneMove` 才是实际二级面板。它不能套用普通根控件的屏幕边缘锚定：在 1920×1080 下，面板放大为 648×666，并居中于 (636,207)。三个分页、艺人卡片、属性、规模、价钱和确认/取消按钮随子树一起缩放，标签沿用放大页面的临时字号适配。

测试覆盖主页面完整签名、运行时选中行容差、滚动控件缺失排除、二级面板结构识别、相似浮层排除，以及 1920×1080 居中坐标。

二级页的三个标签与内容面板是四个兄弟节点。缩放必须枚举 `PlaneMove` 的全部直接子节点，再分别遍历子树；只从 `first_child` 调用子树模板会遗漏内容面板。回归测试覆盖全部兄弟节点和内容子控件恰好访问一次、遍历上限及回调修改兄弟链的情况。
