- 通告遍历的根保护在进入回调置位，在所有子节点完成后清除；首个字幕的修正仍在原时机执行。
- 子树遍历保留各页原有最大深度及每个父节点的子节点上限；在访问子节点前保存 next-sibling，避免 Move 改链造成漏遍历。
- 根节点准备失败时停止该子树；不注册、不回放不属于当前页面的缓存。
